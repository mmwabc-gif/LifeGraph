# 人生图谱 LifeGraph v0.0.8

人生图谱是一个以生命时间为骨架、以本地加密仓库保存事件、记忆、计划与人生资料的个人数字档案系统。

> v0.0.8 是“人生资料系统”稳定版：在 v0.0.7 统一内容中心基础上，加入加密附件、独立资料、资料双重时间关系、资料中心时间轴、目录扫描批量导入、首页快捷月历、农历/节气/传统节日，以及面向大型资料库的附件分片存储、`.lifevault` 流式备份恢复、资料中心分页和图片懒加载。

## v0.0.8 核心能力

### 人生资料与附件

- 事件、记忆、计划均可添加多个附件；新建内容时即可预选附件；
- 照片、文档和其他文件也可作为“独立资料”直接进入资料库，无需先创建父内容；
- 附件原文件使用仓库主密钥 AEAD 加密保存，文件名、MIME、大小、摘要、时间与来源关系等元数据继续加密存入 SQLite；
- 单个普通附件当前限制 50 MB；GB/几十 GB 大文件、视频分块加密与在线播放留到 v0.0.9；
- 内容软删除时附件保留，恢复后继续可用；永久删除时同步清理关联附件。

### 资料双重时间关系

资料同时保留两种关系：

1. **内容关系**：它来自哪条事件、记忆或计划；独立资料则无父内容；
2. **资料自身时间**：用于进入人生资料时间轴，不会反向移动父内容。

时间识别优先级：

- 图片：EXIF `DateTimeOriginal` → `DateTimeDigitized` → `DateTime`；
- Office / OpenDocument：尽量读取内部创建/修改时间；
- PDF：尽量读取 CreationDate / ModDate；
- 普通文件：浏览器提供的 `lastModified`；
- 内容附件仍无可用时间时：明确日级来源日期 → 附件添加时间；
- 独立资料无可用时间时：资料导入时间。

极少数历史异常资料仍可通过【归入来源/添加时间】手工修复时间轴归属。

### 资料中心

- 资料中心默认采用纵向时间轴，也可切换到列表模式；
- 按“年 → 月 → 日 → 资料”组织，支持年度、月份和日期级折叠；
- 同一天资料集中在同一时间节点，照片显示缩略图，文档/其他文件显示紧凑卡片；
- 支持文件名/来源标题、资料类别、日期范围和排序筛选；
- 可从资料跳到自身时间轴日期，也可反向跳回来源事件/记忆/计划；
- 图片支持沉浸式预览、上一张/下一张、滚轮切换、全屏、右键退出与原图下载；
- 资料中心按 **48 份/批** 分页追加；滚动接近底部再加载下一批；
- 图片缩略图使用 `IntersectionObserver` 可视区懒加载，远离视口时不解密原图。

### 目录扫描与批量导入

- 资料中心支持【扫描目录】，递归读取用户主动选择的本地目录及子目录；
- 扫描后先预览，不立即写入仓库；
- 自动排除常见隐藏/系统文件、空文件和超过 50 MB 的文件；
- 浏览器计算 SHA-256，识别目录内重复；后端再检查仓库已有重复；
- 重复资料默认不选中，真正导入时后端再次校验；
- 保留目录内相对路径作为加密元数据，不保存 Windows 绝对路径；
- 单次扫描暂定最多 1000 个文件。

### 附件存储扩展性

附件密文按 UUID 前两位自动分片：

```text
data/attachments/
├─ 00/
├─ 01/
├─ ...
├─ a7/
│  └─ <UUID>.lgatt
└─ ff/
```

- 最多自然分散到 256 个目录；
- 旧版 `data/attachments/<UUID>.lgatt` 平铺文件启动时自动迁移；
- 如果个别旧文件暂时无法移动，读取链路仍回退兼容旧路径；
- `.lifevault` 内部逻辑路径不受本地物理分片影响。

### `.lifevault` 大型备份性能

- `.lifevault` 当前格式：**format v2**；继续兼容旧 format v1 导入；
- 手动导出与自动备份直接在磁盘上流式生成 ZIP；
- SQLite 快照与附件逐个验证、逐个写入，不再把整个资料库组装进内存；
- 导入检查和正式恢复先流式落入临时文件，再逐项校验/恢复；
- 恢复前救援备份同样使用磁盘流式链路；
- 大型备份导入设置 2 TB 安全上限，该限制用于防止异常占满磁盘，并非内存限制。

### 首页快捷月历与中国时间信息

- 首页标题区中间提供紧凑月历，点击日期直接打开对应日详情；
- 年月标题可点击选择其他年月，并支持【回到本月】；
- 月历按周一到周日排列；
- 公历数字为前景，农历/节气/传统节日作为横向底纹，不增加日期格高度；
- 传统节日 ＞ 二十四节气 ＞ 普通农历；
- 节气与重要传统节日使用暖红/中国红强调；
- 当前传统节日包括春节、元宵、清明、端午、七夕、中秋、重阳、腊八、除夕；
- 右侧抽屉的月视图与日详情顶部星期视图复用同一套农历/节气/节日显示。

### 时间图谱与右侧详情

- 首页支持日／月／年三级全范围图谱，默认进入月视图；
- 年、月、日详情均可添加对应粒度的事件、记忆和计划；
- 右侧抽屉中的事件、记忆、计划列表支持独立展开/收起；
- 资料区超过 6 条时默认折叠，可展开全部；
- 支持全屏阅读、上一/下一有内容时间范围和键盘切换；
- 首页和全页视图均提供【记一记】快捷入口，记忆使用 TinyMCE 富文本。

### 统一内容中心、标签和搜索

- 事件、记忆、计划共用统一标签；
- 内容中心统一浏览、关键词检索、类型/日期/标签筛选与排序；
- 支持单条快速整理标签和多选批量添加/移除标签；
- 统一搜索与标签地图筛选覆盖三类内容；
- 旧记忆专用搜索/标签接口继续保留兼容。

## 数据与迁移

当前数据库 schema：**v7**。

主要迁移：

- schema v5：统一 `content_tags`；
- schema v6：新增 `attachments` 加密附件元数据表；
- schema v7：附件 `kind/content_id` 改为可选，使资料与内容关系正式解耦；
- 旧内容、标签和附件均执行非破坏性迁移；
- 原私人正文与资料元数据不会被改写为明文。

当前 `.lifevault` 写出 **format v2**，并兼容导入旧 format v1。

## 时间范围模型

```text
年：time_scope = year  / period_key = YYYY
月：time_scope = month / period_key = YYYY-MM
日：time_scope = day   / period_key = YYYY-MM-DD
```

年度/月度内容不会被错误展开成每一天的内容记录；月、年状态按下级内容向上聚合。资料则按其独立 `timeline_date` 参与日/月/年状态与资料时间轴。

## Windows 启动

首次运行：

```text
start.bat
```

脚本会创建 `.venv`、安装依赖、启动服务并打开：

```text
http://127.0.0.1:8765
```

环境初始化后也可使用：

```text
start_server_only.bat
```

PowerShell：

```powershell
./start.ps1
```

## 手动启动

```powershell
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install -e ".[dev]"
python scripts\run_dev.py
```

## 数据目录

默认运行数据位于：

```text
data/
```

`.gitignore` 排除数据库、`vault.json`、附件密文、自动备份、WAL、SHM、日志、缓存和虚拟环境。稳定源码包只保留必要源码与 `data/.gitkeep`。

可通过环境变量更改数据目录：

```text
LIFEGRAPH_DATA_DIR=D:\LifeGraphData
```
