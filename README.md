# 人生图谱 LifeGraph v0.0.10

人生图谱是一个以生命时间为骨架、以本地加密仓库自动收集、识别、整理个人数字资料的本地优先人生档案系统。

> v0.0.10 是“自动资料时间索引与十字时间轴”稳定版：重点从“用户主动整理”转向“系统自动发现与整理”。照片、视频和文档进入 LifeGraph 后，会尽量自动识别真实时间、建立可索引时间结构，并映射到人生图谱。

## v0.0.10 核心能力

### 自动资料时间索引

- 数据库升级到 schema v11；
- 资料拥有可索引的发生时间、结束时间、时间精度、来源、置信度和时区信息；
- 原始 EXIF / 媒体 / 文件时间等敏感细节继续保存在加密 metadata；
- 历史 v0.0.9 资料可后台回填时间索引，支持暂停/继续和失败隔离；
- 启动、登录和资料中心打开不会同步执行全库回填。

### 年月日十字时间轴

资料中心提供三层常驻横轴：

```text
年：2024  2025[5]  2026[40] ...
月：1月[3]  2月  3月[32] ...
日：1  2  3 ... 9[1] ... 31
                     │
                     └─ 当天 00:00 → 24:00 日内资料轴
```

- 年、月、日采用分段色带表现；
- 无资料时间段弱化并不可点击；
- 进入资料中心默认定位当前年度；
- 点击年或月可自动落到该范围内最近有资料的日期；
- 点击日直接展开当天时分秒资料；
- 图片、视频和文档默认只显示时间、类型、文件名、大小等轻量信息，原始媒体仅在查看/播放/下载时读取。

### 大量资料浏览优化

- 年/月/日/小时使用轻量统计索引；
- 密集日内资料按分钟、10 分钟或小时自适应聚合；
- 单日资料分页继续加载；
- 支持上一/下一有资料日期快速跳转；
- 年/月/日右侧抽屉先用 SQLite `timeline_at` 索引筛当前范围，再只解密当前页；
- 抽屉资料默认 12 项/批，不再因为资料库总量增长而先解密整库 metadata。

### 本机自动扫描与增量导入

资料中心新增“自动扫描”扫描源管理：

- 可配置本机照片、视频、文档等长期扫描目录；
- 解锁后自动执行一次增量扫描，也可手动立即扫描；
- 支持暂停/继续；
- 未变化文件直接跳过；
- 文件重命名/移动可通过文件身份避免重复导入；
- 源文件删除只标记源缺失，不删除 LifeGraph 中已经归档的加密副本；
- 普通资料复用 `blob-v1`，大型资料复用 `chunked-v1`；
- 大文件扫描由后端直接读取本机源文件并分块加密，不通过浏览器重复上传。

扫描源绝对路径以加密形式保存。增量索引只保存必要的相对路径哈希、大小、mtime 和文件身份信息。

### 时间待确认与人生图谱联动

- 人生图谱日期格可根据结构化资料时间统计自动显示“有资料”状态；
- 首页/全页/年/月视图不再为了资料点亮逐条解密附件；
- 资料中心提供“时间待确认”入口，集中处理无时间或低置信度资料；
- 支持手工修正到日期或时分秒；
- 手工确认后使用高置信度 `manual` 时间来源，原始识别时间保留在加密 metadata 中。

### v0.0.9 既有大文件与影音能力

- GB / 数十 GB `chunked-v1` 分块 AES-GCM；
- 暂停/继续/断点恢复和重复检测；
- 视频时长、分辨率、编码和加密封面；
- HTTP Range / 206 随机解密播放及拖动；
- DTS / AC-3 等浏览器不兼容音轨的 MP3/AAC 派生兼容层；
- `.lifevault v3` 核心备份与 `data/media` 大型媒体分层；
- 大型媒体本地/外置盘增量备份与完整性校验。

## 数据与格式

```text
应用版本：0.0.10
数据库：schema v11
.lifevault：format v3
大型媒体：chunked-v1
普通附件：blob-v1
```

主要数据目录：

```text
data/
├─ vault.json
├─ lifegraph.db
├─ attachments/        # 普通附件密文
├─ media/              # 大型原始媒体分块密文
├─ previews/           # 加密视频封面
├─ audio_compat/       # 可重建浏览器兼容音轨
├─ backups/auto/       # 自动核心备份
└─ recovery/           # 恢复前救援备份
```

旧 schema v8 数据库可自动非破坏性升级到 schema v11。`.lifevault v3` 继续兼容导入历史 format v1 / v2。

## Windows 启动

```text
start.bat
```

服务默认打开：

```text
http://127.0.0.1:8765
```

环境已初始化时也可使用：

```text
start_server_only.bat
```

PowerShell：

```powershell
./start.ps1
```
