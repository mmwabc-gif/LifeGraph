# LifeGraph v0.0.4.7 验收清单

## 1. 版本与兼容

- [ ] 首页构建标识、`/health`、`/api/v1/system/status` 与 Python 包版本均为 `0.0.4.7`；
- [ ] 数据库继续使用 schema v3，无需迁移；
- [ ] 原 PIN、恢复密钥、事件、记忆、计划和现有 `.lifevault` 均可继续使用。

## 2. 设置分区

- [ ] 个人设置窗口按“个人档案／安全设置／备份与迁移”显示三个独立分组；
- [ ] 每组有通栏浅色标题、图标、边框和独立留白；
- [ ] 修改 PIN、修改恢复密钥和安全状态都位于“安全设置”中；
- [ ] 自动备份、健康状态、导出和恢复都位于“备份与迁移”中；
- [ ] 首页与全页视图打开的是同一个重构后的设置窗口。

## 3. 个人档案默认只读

- [ ] 打开个人设置时，姓名和出生日期以只读摘要显示；
- [ ] 默认不显示个人档案输入框、当前 PIN 和保存按钮；
- [ ] 点击“编辑个人档案”后才进入编辑态并聚焦姓名输入框；
- [ ] 点击“取消编辑”清除确认 PIN，并返回只读摘要；
- [ ] 取消编辑不会关闭个人设置窗口；
- [ ] 保存后首页姓名、出生日期相关进度与图谱仍正常更新。

## 4. 恢复密钥文案

- [ ] 初始化、解锁、重置 PIN、个人设置和备份恢复界面统一使用“恢复密钥”；
- [ ] 不再将恢复密钥描述成备份专用 PIN；
- [ ] 修改恢复密钥仍要求当前 PIN，并保持登录 PIN、主密钥和业务密文不变；
- [ ] 旧备份仍使用其导出时对应的 PIN 或恢复密钥。

## 5. 滚动与响应式

- [ ] 设置标题和关闭按钮固定在可视区域；
- [ ] 三个分组可以滚动访问到底部，滚动条轨道保持隐藏；
- [ ] `1366 × 768`、窄屏和低高度窗口均可访问全部按钮；
- [ ] 移动端只读摘要改为单列，编辑按钮占满可用宽度。
