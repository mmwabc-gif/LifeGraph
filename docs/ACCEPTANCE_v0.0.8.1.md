# LifeGraph v0.0.8.1 验收清单

## 附件基础

- [ ] 事件、记忆、计划卡片均可打开【附件】区域；
- [ ] 可选择本地文件上传，上传后立即出现在附件列表；
- [ ] 中文文件名可以正常显示和下载；
- [ ] 单个超过 50 MB 的文件会被明确拒绝；
- [ ] 下载后的文件内容与上传前完全一致；
- [ ] 删除附件不会删除正文内容；
- [ ] `data/attachments/*.lgatt` 中搜索不到附件原始明文和原始文件名。

## 生命周期

- [ ] 内容移入回收站后附件仍保留；
- [ ] 恢复内容后原附件仍可下载；
- [ ] 彻底删除内容后对应 `.lgatt` 文件同时删除；
- [ ] 清空回收站时一并清理相关附件。

## 备份与恢复

- [ ] 仓库完整性检查会验证附件；
- [ ] 导出的 `.lifevault` manifest `format_version` 为 2；
- [ ] 有附件时备份包包含 `repository/attachments/*.lgatt`，其中不出现附件明文；
- [ ] 导入演练显示附件验证数量；
- [ ] 从 `.lifevault` 正式恢复后附件仍可下载；
- [ ] 旧 format v1 无附件备份仍可导入。

## 回归

- [ ] 原事件 / 记忆 / 计划 CRUD 正常；
- [ ] 标签、统一搜索、内容中心、地图筛选正常；
- [ ] 自动备份与恢复前救援备份正常；
- [ ] 首页默认月视图保持不变。
