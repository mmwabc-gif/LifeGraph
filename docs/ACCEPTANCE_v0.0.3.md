# LifeGraph v0.0.3 验收清单

验收日期：2026-08-06  
正式版本：v0.0.3  
数据库 schema：v3

## 内容管理

- [x] 年、月、日范围中的事件、记忆和计划均可新增、查看与编辑；
- [x] 编辑表单正确回填标题和正文；
- [x] 编辑后保留原时间范围和创建时间，`revision` 自动递增；
- [x] 旧 revision 请求返回冲突，不会静默覆盖较新内容；
- [x] 内容卡片“…”菜单可编辑或删除，并支持外部点击和 Esc 关闭。

## 删除与回收站

- [x] 三类内容均可软删除并立即从普通详情和图谱标记中移除；
- [x] 软删除前后 nonce 与 ciphertext 保持不变；
- [x] 已删除内容可在统一回收站查看；
- [x] 恢复后回到原年份、月份或日期范围；
- [x] 单项彻底删除后不可恢复；
- [x] 清空回收站只处理当前档案中已软删除的内容。

## 全页日图与综合首页

- [x] 初始化或解锁后默认进入全页日图；
- [x] 日期连续铺满页面，不按年龄分行、不显示年序号；
- [x] 可定位今天、悬停查看日期、点击打开右侧详情；
- [x] 全页模式只保留隐藏滚动条的日期区域滚动；
- [x] 窄屏时顶部区域可自动增高，不覆盖日期格；
- [x] 点击“进入首页”可返回综合工作台；
- [x] 综合首页保留日／月／年三级图谱和进度展示。

## 个人档案与安全

- [x] 可修改姓名和出生日期，保存前验证当前 PIN；
- [x] 修改出生日期会预览超出新图谱范围的内容数量；
- [x] 原有内容保持原公历日期，不随出生日期平移或删除；
- [x] 可修改 PIN，成功后撤销会话并要求重新解锁；
- [x] 可使用恢复凭据重置忘记的 PIN；
- [x] 修改或重置 PIN 不重写档案、事件、记忆和计划密文；
- [x] 正常桌面高度下个人设置完整显示且不出现滚动条；
- [x] 小屏或高度不足时仍可滚动，滚动条轨道隐藏。

## 交互与回归

- [x] 删除、彻底删除和清空回收站使用应用内确认弹窗；
- [x] 新增或编辑表单发生变化后，关闭、切换、锁定或离开前有未保存提醒；
- [x] 保存、删除、恢复等关键操作有处理中状态并防止重复提交；
- [x] 成功和失败反馈清晰；
- [x] 锁定仓库后无法读取或修改私人内容；
- [x] schema v1／v2 可非破坏性升级到 v3；
- [x] 标题和正文不以明文进入 SQLite、WAL 或 SHM；
- [x] 自动化测试：`62 passed`；
- [x] JavaScript 语法检查通过；
- [x] Python 编译检查通过。

## 验收结论

v0.0.3 已达到正式稳定版提交条件，可提交 Git、创建 `v0.0.3` tag，并进入 v0.0.4 开发。
