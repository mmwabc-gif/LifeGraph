# LifeGraph v0.0.2 稳定发布归档

## 版本身份

- 项目：人生图谱 / LifeGraph
- 稳定版本：v0.0.2
- 收口日期：2026-08-06
- 上一个稳定版本：v0.0.1
- v0.0.1 基线提交：`d8968bf`
- 数据库 schema：v3
- 自动化测试：35 项通过

## 本阶段目标

实现“日期详情 + 事件 / 记忆 / 计划最小闭环”，并将内容时间范围扩展到整年、整月和具体日期。

## 交付结果

1. 保留完整人生日期格总览；
2. 增加全范围月视图和年视图；
3. 年、月、日均可打开右侧详情抽屉；
4. 年度、月度、日期均可新增事件、记忆和计划；
5. 三类内容继续加密保存；
6. 日期、月份和年份格显示内容状态；
7. 旧数据库自动迁移；
8. 首页进度卡与抽屉交互完成多轮 UI 收口；
9. Windows 启动脚本支持自动重启服务。

## 数据兼容性

- v0.0.1 schema v1 可升级；
- v0.0.2 早期 schema v2 可升级；
- 升级目标为 schema v3；
- 旧按日内容自动回填 `time_scope=day` 与原日期 `period_key`；
- 迁移在事务中执行；
- 不要求用户重新创建仓库。

## 发布包约定

正式源码包不包含：

- `.git/`；
- `.venv/`；
- `__pycache__/`；
- `.pytest_cache/`；
- `*.egg-info/`；
- `data/lifegraph.db`；
- `data/vault.json`；
- 用户事件、记忆和计划；
- 任何本地密钥或私密配置。

## 已知边界

- 内容暂不可编辑；
- 内容暂不可删除和恢复；
- 暂无照片、附件和文件扫描；
- 暂无农历、插件和同步；
- 当前定位为本地优先单仓库应用。

## 下一阶段

v0.0.3 优先完成内容编辑、软删除与恢复，再进入仓库迁移和导出能力。
