# v0.0.1 架构说明

```text
浏览器页面
    ↓ REST / JSON
FastAPI /api/v1
    ↓
VaultManager
    ├─ PIN / 恢复凭据解锁
    ├─ 内存主密钥
    ├─ 内存会话令牌
    └─ Database
          ↓
SQLite（业务正文为 AES-GCM 密文）
```

## 为什么所有界面都走 API

- 后续可将同一后端部署到 VPS；
- 浏览器插件和未来移动端可以复用接口；
- 数据库实现可升级而无需修改客户端；
- 认证、审计和校验集中在后端。

## v0.0.1 的边界

本版本不是正式安全审计版本，也暂未实现：

- 整库 SQLCipher；
- 迁移包；
- 自动备份；
- 插件设备配对；
- 多设备同步；
- 事件和记忆 CRUD。
