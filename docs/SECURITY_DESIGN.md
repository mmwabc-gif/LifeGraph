# v0.0.1 安全设计

## 密钥分层

```text
PIN / 恢复凭据
      ↓ Argon2id
包装密钥
      ↓ AES-GCM
随机仓库主密钥
      ↓ AES-GCM
个人档案正文
```

## 已落实

- PIN 为 6—12 位数字；
- PIN 不直接充当业务数据密钥；
- 主密钥使用安全随机数生成；
- 恢复凭据与 PIN 使用不同盐和 AAD；
- AES-GCM 同时提供加密与完整性验证；
- 会话令牌仅保存在内存与浏览器 `sessionStorage`；
- 本地服务默认只监听 `127.0.0.1`；
- `data/`、数据库和迁移包被 Git 忽略；
- 日志不输出 PIN、恢复凭据或主密钥。

## 原型限制

- Python 无法保证主密钥内存被立即物理清零；
- 本版本使用字段级加密，数据库表结构仍可见；
- 尚未实现错误 PIN 的持久化限速；
- 尚未实现操作系统安全凭据存储；
- 尚未经过第三方安全审计。
