# LifeGraph v0.0.7 验收清单

## 验收结论

LifeGraph v0.0.7 已完成“统一内容整理与浏览”阶段：事件、记忆、计划三类内容已进入统一标签、统一搜索、统一地图筛选和统一内容中心，并具备单条与批量标签整理能力。数据库 schema 正式升级到 v5。

## 统一内容中心

- [x] 内容中心集中展示事件、记忆、计划；
- [x] 支持关键词、类型、日期范围、标签和排序组合条件；
- [x] 结果区独立滚动，上方筛选区保持可用；
- [x] 内容卡片展示类型、标题、时间、摘要和标签；
- [x] 点击内容可打开对应年/月/日详情；
- [x] 关闭详情后返回原内容中心；
- [x] 返回时保留筛选、排序、结果和滚动位置；
- [x] 普通模式可单条整理标签；
- [x] 批量整理模式按需进入，默认界面不显示批量控件；
- [x] 支持全选当前结果、清空选择、批量添加和移除标签；
- [x] 批量操作先整体验证，失败时不会产生半完成状态。

## 统一标签

- [x] 事件、记忆、计划共用统一标签；
- [x] 三类内容均可绑定、解绑和新建标签；
- [x] 标签管理显示三类使用次数；
- [x] 标签重命名后搜索、筛选和内容卡片同步；
- [x] 删除标签只解除关联，不删除内容；
- [x] 软删除内容保留标签，恢复后标签仍在；
- [x] 永久删除内容时清理标签关联。

## 统一搜索与地图筛选

- [x] 搜索支持事件、记忆、计划类型组合；
- [x] 支持标题/正文关键词；
- [x] 支持开始日期和结束日期；
- [x] 支持多标签交集筛选；
- [x] 年/月内容按时间范围交集正确匹配；
- [x] 搜索结果可定位到对应详情；
- [x] 地图标签筛选覆盖三类内容；
- [x] 日级、月级、年级内容按各自时间粒度高亮；
- [x] 完整人生图谱结构不会因为筛选而消失。

## 界面与交互

- [x] 内容中心布局已压缩并提高结果列表可视高度；
- [x] 卡片不再被 Grid 压缩成细横条；
- [x] 单条整理入口已整合到标题行；
- [x] 批量选择框在批量模式中显示在标题前；
- [x] 首页默认进入月视图，后续可正常切换日/月/年。

## 数据、兼容与安全

- [x] schema v4 可非破坏性迁移到 v5；
- [x] `memory_tags` 自动迁移到统一 `content_tags`；
- [x] 旧记忆搜索与记忆标签地图接口继续兼容；
- [x] 事件、记忆、计划正文继续保持加密；
- [x] `.lifevault` 格式保持兼容；
- [x] 前端、后端、状态接口、Python 包和备份生产者版本统一为 0.0.7。
