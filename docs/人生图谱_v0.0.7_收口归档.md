# 人生图谱 v0.0.7 收口归档

日期：2026-08-08  
正式版本：v0.0.7  
数据库 schema：v5

## 阶段定位

v0.0.7 完成“统一内容整理与浏览”。LifeGraph 不再只有记忆具备搜索和标签能力，事件、记忆、计划三类内容已经进入统一的标签、搜索、筛选、地图高亮和内容中心。

## 本阶段完成

### 统一内容中心

- 集中浏览事件、记忆、计划；
- 关键词、类型、日期范围、标签、排序可组合使用；
- 内容结果独立滚动；
- 点击内容进入对应时间详情；
- 关闭详情后恢复原内容中心状态和滚动位置；
- 内容卡片显示标签并支持单条快速整理；
- 支持按需进入批量整理模式；
- 支持全选当前结果、批量添加/移除标签。

### 统一标签

- 建立 `content_tags` 统一关联；
- 事件、记忆、计划均可使用同一标签；
- 标签管理统计扩展到三类内容；
- 软删除、恢复和永久删除均正确维护标签关系。

### 统一搜索与筛选

- 新增统一全文搜索；
- 支持内容类型、日期和多标签交集；
- 新增统一地图标签筛选；
- 年/月/日三种时间粒度按自身范围高亮；
- 保留 v0.0.6 记忆专用搜索/筛选 API 兼容。

### 界面收口

- 内容中心提高可用高度并压缩筛选区；
- 修复结果卡片被压成横条的问题；
- 筛选控件改为紧凑同行布局；
- 批量工具栏改为底部按需显示；
- 单条整理按钮移入标题行；
- 批量选择框移到标题前；
- 首页默认视图改为月视图。
