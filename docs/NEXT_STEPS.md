# LifeGraph v0.0.4 后续开发建议

v0.0.3 已完成内容编辑、软删除、回收站、全页日图默认入口，以及姓名、出生日期和 PIN 安全设置。v0.0.4 建议进入“仓库可迁移、可备份、可验证”阶段。

## 第一优先级：仓库备份与迁移

1. 创建一致性 SQLite 快照；
2. 导出最小 `.lifevault` 迁移包；
3. 迁移包包含版本、校验摘要、数据库和必要密钥槽信息；
4. 导入前验证完整性和版本兼容性；
5. 提供恢复演练与结果报告；
6. 导入失败时保持原仓库不变。

## 第二优先级：恢复凭据与密钥管理

1. 修改恢复凭据；
2. 轮换 PIN 与恢复密钥槽；
3. 显示密钥槽创建和最近修改时间；
4. 高风险操作要求再次验证凭据；
5. 增加不包含敏感正文的安全审计摘要。

## 第三优先级：内容查找与整理

1. 按时间范围搜索；
2. 按事件、记忆、计划筛选；
3. 抽屉内容排序和折叠；
4. 移动内容到其他年、月或日期；
5. 回收站筛选和批量恢复。

## 暂不进入

- 照片和附件；
- 文件扫描；
- 农历；
- 浏览器插件；
- 云同步。
