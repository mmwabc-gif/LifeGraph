# LifeGraph 后续计划

## 当前稳定基线

- 正式版本：v0.0.10
- 数据库：schema v11
- `.lifevault`：format v3
- 普通资料与大型媒体双通道完成
- 自动扫描、时间识别、结构化索引、十字时间轴与人生图谱联动完成

## 后续优先候选

### 1. 地点 / GPS 与人生地图

- 从照片 EXIF GPS 和视频/文档可用位置元数据提取地点；
- 保存结构化地点索引与置信度；
- 在不强迫用户整理的前提下，自动形成“何时去了哪里”的人生地图；
- 地点未知或不可靠时允许待确认和批量修正。

### 2. 人物与关系

- 可选本地人脸检测/聚类；
- 人物名称由用户少量确认，系统批量传播；
- 人物与时间、地点、资料形成交叉检索。

### 3. 可选本地 AI 辅助整理

- 图片/视频内容描述；
- OCR 与文档摘要；
- 自动标签建议；
- 旅行、活动、阶段性事件聚类。

AI 应作为可关闭的增强层，不成为资料入库和时间轴工作的前置条件。

### 4. R2 / NAS 远端增量同步

复用现有 media inventory、密文分块、增量判断和 SHA-256 校验，把本地/外置盘媒体备份扩展到 R2 或 NAS，并重点处理断点、限速、失败恢复和凭据安全。

### 5. 自动扫描增强

- 可选文件系统 watcher；
- 扫描源排除规则；
- 网络盘/可移动盘状态；
- 大规模重命名/移动识别；
- 扫描历史与诊断。
