# LifeGraph 后续计划

## 当前稳定基线

- 正式版本：v0.0.8
- 数据库：schema v7
- `.lifevault`：format v2
- 人生内容库 + 人生资料库闭环完成
- 普通资料库已具备附件分片、流式备份恢复、资料分页和图片懒加载能力

## v0.0.9：大文件与影音资料

v0.0.9 重点解决“单个文件很大”，不再继续扩大 v0.0.8 普通附件模型。

### 1. 大文件分块加密

- 支持 GB / 数十 GB 单文件；
- 固定或自适应块大小；
- 每块独立认证加密；
- 内存中只保留少量数据块；
- 设计可随机定位的加密块索引。

### 2. 断点上传与失败恢复

- 大文件分块上传；
- 中断后从已确认块继续；
- 上传会话与临时块安全清理；
- SHA / 大小 / 块完整性最终校验。

### 3. 视频资料能力

- 提取时长、分辨率、编码等元数据；
- 生成并加密保存视频封面/缩略图；
- 资料中心显示视频卡片；
- 浏览器内置视频播放器；
- 支持播放/暂停、进度拖动、音量、倍速和全屏。

### 4. HTTP Range 与随机解密

- 浏览器请求视频某一时间段时，只读取对应密文块；
- 后端按 Range 定位并解密所需数据；
- 避免播放前完整解密大型视频。

### 5. 大型媒体备份边界

评估将核心仓库与大型媒体分层：

```text
核心 .lifevault
├─ 数据库
├─ 配置
├─ 中小照片 / 文档
└─ 必要索引

大型媒体库
├─ 视频
├─ 大型原片
└─ 独立增量备份 / R2 / NAS / 外置硬盘
```

目标是避免数百 GB / TB 媒体每次完整重打 `.lifevault`。
