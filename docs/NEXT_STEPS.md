# LifeGraph 下一阶段计划

## v0.0.7：统一内容整理与浏览

v0.0.6 已完成“记忆”的搜索、时间范围筛选、标签、地图高亮和标签管理。下一阶段建议在不破坏当前记忆工作流的前提下，把整理能力逐步扩展到其他内容类型。

建议顺序：

1. 统一内容中心：集中浏览事件、记忆、计划，并按类型、时间范围排序；
2. 将标签能力扩展到事件和计划，尽量复用 v0.0.6 的 `tags` 体系；
3. 将全局搜索从“记忆搜索”扩展为事件 / 记忆 / 计划统一搜索；
4. 增加基础统计，例如每年记录数量、标签使用频次和记录活跃区间；
5. 评估是否在这一阶段加入“常用标签”与快速筛选入口。

## 暂缓项

- Markdown 混合编辑：继续不放入日常记录表单；
- 图片和附件：涉及加密附件与 `.lifevault` 打包，建议单独阶段处理；
- 照片 EXIF 与本地文件挂接：建议在附件数据模型确定后实施；
- 多端同步：建议在本地内容整理稳定后再做；
- AI 总结与自动标签：等待内容结构和检索接口进一步稳定。
