# LifeGraph 下一阶段计划

## v0.0.8：附件与人生资料库

v0.0.7 已完成事件、记忆、计划三类内容的统一标签、统一搜索、统一地图筛选与内容中心整理。下一阶段建议开始接入真实照片和文件，让 LifeGraph 从“文字人生数据库”进入“个人数字档案”阶段。

建议顺序：

1. 建立附件数据模型：附件可挂接到具体日期，也可挂接到事件、记忆或计划；
2. 先支持本地图片与普通文件的上传/挂接、列表展示和安全删除；
3. 图片提供缩略图与基础预览，普通文件提供类型、大小、文件名和打开/下载入口；
4. 明确附件加密策略，以及 `.lifevault` 备份包如何携带附件；
5. 在附件模型稳定后加入照片 EXIF 拍摄日期识别；
6. 最后评估指定目录扫描与按日期自动挂接，避免一开始引入过多文件系统复杂度。

## v0.0.8 设计原则

- 本地优先，默认不依赖云端；
- 私人附件应与现有正文一样纳入加密与备份边界；
- 大文件不能拖慢普通文字内容的读取；
- 附件删除、恢复和备份语义必须清楚，避免“正文恢复了但附件丢失”；
- EXIF 和目录扫描属于自动归档能力，应建立在稳定附件模型之后。

## 暂缓项

- 多设备实时同步；
- 云端协作；
- AI 自动总结、自动标签和人物关系抽取；
- Markdown 混合编辑；
- 浏览器插件与桌面悬浮进度条的深度联动。
