# LifeGraph v0.0.5 后续开发建议

v0.0.4 已完成加密仓库的备份、迁移、恢复、自动备份、健康验证、恢复密钥轮换和个人设置结构收口。下一阶段建议进入“内容查找与整理”，让已经保存的事件、记忆和计划更容易被重新找到和重新组织。

## 第一优先级：全局搜索

1. 搜索事件、记忆和计划标题与正文；
2. 按内容类型、时间范围、完成状态和是否已删除筛选；
3. 搜索结果显示所属年／月／日并可直接打开详情；
4. 搜索词只在仓库解锁后进入内存，不写入浏览器持久存储；
5. 评估解密后内存搜索与安全索引两种实现，优先保证隐私。

## 第二优先级：内容整理

1. 抽屉内按创建时间、更新时间和标题排序；
2. 将内容移动到其他年、月或具体日期；
3. 支持内容类型之间的安全转换或复制；
4. 回收站按类型筛选和批量恢复／彻底删除；
5. 对大量内容提供折叠、分页或增量加载。

## 第三优先级：备份诊断增强

1. 对历史列表中的任意备份执行完整验证；
2. 记录最近手动恢复演练的时间和结果；
3. 检测自动备份目录不可写和可用空间不足；
4. 生成可归档的备份健康报告；
5. 为异盘复制和离线备份目标预留配置。

## 后续阶段

- 照片与附件；
- EXIF 日期归档；
- 指定目录文件扫描；
- 农历和固定纪念日；
- 浏览器插件；
- 多设备同步与冲突处理。

## v0.0.5 建议拆分

- v0.0.5.1：搜索 API 与基础搜索页；
- v0.0.5.2：筛选、结果定位与高亮；
- v0.0.5.3：内容移动和排序；
- v0.0.5.4：回收站批量操作；
- v0.0.5.x：交互收口、测试与稳定版归档。
