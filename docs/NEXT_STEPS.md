# LifeGraph 后续计划

## 当前稳定基线

- 正式版本：v0.0.9
- 数据库：schema v8
- `.lifevault`：format v3
- 普通资料与大型媒体双通道完成
- GB / 数十 GB 上传、视频播放、浏览器音频兼容和媒体分层备份闭环完成

## 后续优先候选

### 1. R2 / NAS 大型媒体远端增量同步

复用 v0.0.9 已有的 media inventory、密文分块、增量判断与 SHA-256 校验，把本地/外置盘媒体备份扩展到 R2 或 NAS。重点考虑断点、限速、失败恢复和凭据安全。

### 2. 媒体库批量管理

- 大型媒体离线/在线批量审计；
- 备份盘历史孤儿块显式清理；
- 批量重新生成封面或兼容音轨；
- 多音轨选择与播放器音轨切换。

### 3. 目录监控与增量导入

- Python 文件系统扫描模式；
- 指定目录定期扫描；
- 新增/变化文件增量导入；
- 保持“不擅自读取未授权目录”的本地优先边界。

### 4. 人生关系与地点

- 人物关系；
- 地点与人生地图；
- 资料/事件与地点关联。

### 5. AI 辅助整理

在不破坏本地加密边界的前提下，探索可选的本地模型辅助描述、标签建议、资料归类与摘要。
