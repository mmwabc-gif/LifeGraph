# LifeGraph v0.0.3 后续开发建议

v0.0.2 已完成年、月、日范围的事件、记忆和计划新增、读取、加密保存与图谱状态闭环。

## 第一优先级：内容管理闭环

1. 编辑事件、记忆和计划；
2. 软删除内容；
3. 已删除内容恢复；
4. 内容操作确认与错误提示；
5. 抽屉内容排序和折叠。

## 第二优先级：仓库管理

1. 修改 PIN；
2. 自动锁定倒计时提示；
3. 一致性数据库快照；
4. `.lifevault` 最小迁移包；
5. 恢复演练与校验报告。

## 第三优先级：使用体验

1. 时间范围搜索；
2. 事件、记忆、计划筛选；
3. 键盘导航；
4. 移动端抽屉优化；
5. 空状态与内容密度展示。

## 暂不进入

- 照片和附件；
- 文件扫描；
- 农历；
- 浏览器插件；
- 云同步。
