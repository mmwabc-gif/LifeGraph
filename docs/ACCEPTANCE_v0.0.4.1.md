# LifeGraph v0.0.4.1 验收清单

## 仓库检查

- [ ] 仓库锁定时不能调用备份检查或导出接口。
- [ ] 解锁后“检查仓库完整性”显示通过。
- [ ] 检查结果包含 schema 版本和已验证加密记录数。

- [ ] 外键错误数为 0。

## `.lifevault` 导出

- [ ] 导出文件扩展名为 `.lifevault`。
- [ ] 包内只有 `manifest.json`、`repository/vault.json`、`repository/lifegraph.db`。
- [ ] 清单文件的大小和 SHA-256 与实际文件一致。
- [ ] 包字节中找不到测试姓名、事件标题、正文或 PIN 明文。
- [ ] 刚写入 WAL 的内容也包含在导出快照中。
- [ ] 软删除内容仍存在于备份，可在恢复后回收站中查看。
