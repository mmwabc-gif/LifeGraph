# 人生图谱 v0.0.4 收口归档

收口日期：2026-08-07

测试结果：91 passed

## 阶段目标

v0.0.4 将 v0.0.3 的加密内容仓库扩展为完整的本地备份、迁移、验证与恢复系统，使人生图谱不再只“能保存”，而是具备可持续迁移和灾难恢复基础。

## 已完成

- SQLite Backup API 一致性快照；
- `.lifevault` 加密备份格式和 SHA-256 清单；
- 导入前恢复演练与凭据验证；
- 正式恢复前安全备份和失败自动回滚；
- 每天／每周自动备份、保留数量和历史管理；
- 最近备份健康、超期、失败、损坏和快速验证；
- 恢复密钥轮换、密钥槽状态和安全审计摘要；
- 个人设置三组分区与默认只读个人档案；
- 首页和全页视图中的备份提醒入口。

## 数据与安全

- schema 保持 v3；
- `.lifevault` 中的数据继续保持加密；
- PIN 与恢复密钥都只是包装同一个随机主密钥；
- 修改任一凭据都不重写事件、记忆和计划密文；
- 旧备份使用导出时的旧凭据，新备份使用当前凭据；
- 恢复替换失败时自动回滚；
- 发布包不包含数据库、`vault.json`、备份、日志、缓存或个人数据。
