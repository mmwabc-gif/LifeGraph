# LifeGraph v0.0.8 Stable Release

发布日期：2026-08-09

## 定位

v0.0.8 是 LifeGraph 的“人生资料系统”稳定版。它把 v0.0.7 的事件/记忆/计划内容体系扩展为“内容 + 资料”双体系：资料可以是内容附件，也可以独立存在；资料拥有自己的真实时间关系，并可长期进入人生资料时间轴。

## 主要能力

- 加密附件与图片预览；
- EXIF / 文档内部时间 / 文件时间识别；
- 资料自身时间与父内容时间解耦；
- 独立资料导入；
- 资料中心时间轴与列表模式；
- 年/月/日三级资料折叠与来源反向跳转；
- 指定目录扫描、重复检查与批量加密导入；
- 首页可切换年月的快捷月历；
- 农历、二十四节气、春节/元宵/清明/端午/七夕/中秋/重阳/腊八/除夕；
- 附件 UUID 分片存储与旧平铺附件兼容迁移；
- `.lifevault` 大型备份磁盘流式导出、自动备份、检查与恢复；
- 资料中心 48 份/批分页和图片可视区懒加载。

## 数据与格式

- 数据库 schema：**v7**；
- `.lifevault`：**format v2**；
- 正式应用版本：**0.0.8**；
- 本地附件物理路径：`data/attachments/<uuid前2位>/<UUID>.lgatt`；
- `.lifevault` 内部附件路径继续为 `repository/attachments/<UUID>.lgatt`。

## 升级兼容

- 从 v0.0.7 / schema v5 可非破坏性升级；
- schema v6 新增附件表；schema v7 允许资料无父内容；
- 旧标签、正文和附件关系保留；
- v0.0.8.8 之前的平铺附件启动后自动迁移；迁移失败时仍可回退读取；
- `.lifevault` v2 继续接受旧 format v1 备份。

## 当前边界

v0.0.8 重点解决“资料很多”和“备份很大”，不处理“单个文件特别大”。单文件 50 MB 限制仍保留。GB / 数十 GB 视频、大文件分块加密、断点续传、视频在线播放与大型媒体分层备份进入 v0.0.9。
