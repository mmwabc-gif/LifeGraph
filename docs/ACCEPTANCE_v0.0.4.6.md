# LifeGraph v0.0.4.6 验收清单

## 1. 版本与兼容性

- [ ] 首页构建标识、`/health`、`/api/v1/system/status` 与 Python 包版本均为 `0.0.4.6`；
- [ ] 直接覆盖 v0.0.4.5 后可继续使用原 PIN 解锁；
- [ ] 数据库仍为 schema v3，不要求迁移或重新初始化；
- [ ] 旧版 `vault.json` 没有最近验证字段时可正常读取。

## 2. 备份健康状态

- [ ] 未启用自动备份时显示“未启用”；
- [ ] 已启用但没有备份时显示“需备份”；
- [ ] 最近备份通过完整验证时显示“健康”；
- [ ] 最近备份未有验证摘要时显示“待验证”；
- [ ] 超过每天或每周周期时显示“已超期”及超期时长；
- [ ] 最近备份失败或文件损坏时显示明确错误状态；
- [ ] 健康摘要不显示私人档案或凭据内容。

## 3. 最近备份快速验证

- [ ] 点击“验证最近备份”会读取最近自动备份的实际落盘文件；
- [ ] 验证 ZIP 结构、文件大小、SHA-256、SQLite、外键和全部加密记录；
- [ ] 成功后显示验证时间、文件名和加密记录数量；
- [ ] 验证不会覆盖当前 `vault.json` 或 `lifegraph.db`；
- [ ] 没有备份时按钮不可用；
- [ ] 损坏的 ZIP、数据库或密文返回可控错误，不导致服务崩溃。

## 4. 超期与异常提醒

- [ ] 自动备份超期、失败、损坏或待验证时，“个人设置”按钮显示提醒点；
- [ ] 首页和全页视图的提醒状态一致；
- [ ] 同一状态在一次页面会话中不会重复弹出提示；
- [ ] 健康或关闭自动备份后提醒点消失。

## 5. 自动备份安全性

- [ ] 新生成的自动备份在记录成功前完成落盘文件恢复验证；
- [ ] 验证结果只写入 `vault.json` 的非敏感备份策略摘要；
- [ ] 自动备份仍保存到 `data/backups/auto/`；
- [ ] 保留数量清理不触碰当前仓库、手动下载文件或 `data/recovery/`；
- [ ] 自动备份失败不回滚已经成功保存的普通内容。
