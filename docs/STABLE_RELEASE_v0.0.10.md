# LifeGraph v0.0.10 Stable Release

发布日期：2026-08-10

## 定位

v0.0.10 是 LifeGraph 的“自动资料时间索引与十字时间轴”稳定版。它在 v0.0.9 大文件与影音资料能力之上，把 LifeGraph 的长期价值从“手工记录”进一步转向“自动发现与整理既有数字生活资料”。

## 主要能力

- schema v11 结构化资料时间模型；
- 旧资料后台时间索引回填；
- 年/月/日/小时轻量统计；
- 年/月/日三层常驻横向色带轴；
- 单日日内时分秒纵轴；
- 密集资料聚合、分页和相邻资料日期导航；
- 本机扫描源与自动增量扫描；
- 普通/大型资料统一进入现有加密资料库；
- 人生图谱资料日期自动点亮；
- 时间待确认与手工修正；
- 年/月/日详情抽屉按索引分页解密；
- 首页与资料中心 UI 性能/交互收口。

## 数据与格式

- 正式应用版本：**0.0.10**；
- 数据库 schema：**v11**；
- `.lifevault`：**format v3**；
- 大型媒体：**chunked-v1**；
- 普通附件：**blob-v1**。

## 升级兼容

- v0.0.9 / schema v8 可自动升级到 schema v11；
- schema 迁移只建立结构，不在启动时做旧资料全库解密；
- 历史资料通过显式后台任务补时间索引；
- `.lifevault v3` 保持不变并继续兼容 v1/v2 导入；
- 自动扫描源路径若在恢复后的电脑不存在，只显示不可用，不阻断恢复；
- v0.0.9 大型媒体、Range 播放和分层备份模型完整保留。
