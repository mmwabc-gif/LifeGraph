# LifeGraph v0.0.4.2 验收清单

## 自动导入与恢复演练

- [ ] 个人设置可以选择 `.lifevault` 文件；
- [ ] 可以选择“备份 PIN”或“备份恢复凭据”；
- [ ] 输入错误凭据时，恢复演练被拒绝；
- [ ] 文件、凭据或验证方式变化后，“恢复此备份”重新禁用；
- [ ] 演练通过后显示创建时间、schema 和加密记录数量；
- [ ] 演练过程不修改当前仓库；
- [ ] 正式恢复需要应用内二次确认；
- [ ] 恢复前在 `data/recovery/` 自动生成安全备份；
- [ ] 恢复成功后当前会话失效并返回解锁页；
- [ ] 使用导入备份对应的 PIN 或恢复凭据可以解锁；
- [ ] 导入后的个人档案、内容和回收站与备份一致；
- [ ] 恢复前安全备份可以独立还原原仓库。

## 格式与安全

- [ ] 非 `.lifevault` 文件被拒绝；
- [ ] 空文件和超过 512 MB 的文件被拒绝；
- [ ] ZIP 路径、重复条目或额外条目异常被拒绝；
- [ ] `manifest.json` 格式版本不支持时被拒绝；
- [ ] 高于当前程序支持的 schema 被拒绝；
- [ ] 文件大小或 SHA-256 不匹配时被拒绝；
- [ ] SQLite `quick_check` 和外键检查通过；
- [ ] 所有档案、事件、记忆、计划和回收站密文均可解密；
- [ ] 备份 PIN 与恢复凭据不写入 SQLite、`vault.json`、manifest 或 sessionStorage；
- [ ] 当前仓库锁定或会话失效时不能检查或恢复备份。
