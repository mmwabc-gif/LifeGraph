# 人生图谱 LifeGraph v0.0.10 总体设计

日期：2026-08-10

## 一、阶段目标

v0.0.10 的核心不是增加另一套手工资料管理，而是让 LifeGraph 在用户不主动整理的情况下也能够随着个人数字资料持续增长。核心原则：

> 用户负责生活，系统负责收集、识别、整理和串联。

主链路：

```text
本机照片 / 视频 / 文档
    ↓ 自动扫描
时间识别
    ↓
结构化时间索引
    ↓
年 / 月 / 日统计
    ↓
三层横向时间轴
    ↓
日内时分秒纵轴
    ↓
人生图谱日期自动点亮
```

## 二、时间模型

资料保留发生时间、结束时间、精度、来源、置信度和时区。只知道日期时不伪造 `00:00:00`；无法可靠确定时进入“时间待确认”。

时间识别优先使用照片 EXIF、媒体 metadata、文档 metadata、文件名，再回退文件系统时间。手工确认后的原始值仍保存在加密 metadata。

## 三、时间查询与性能

年月日轴不遍历资料正文，只查询轻量统计。选中日期后才分页解密当前日 metadata。密集日资料按分钟/10分钟/小时聚合，并支持继续加载。

年/月/日详情抽屉同样先走 `timeline_at` 数据库范围索引，再对当前页解密，避免全库附件解密。

## 四、十字时间轴

- 年、月、日三层常驻显示；
- 时间段本身作为色带轴段；
- 有资料显示 `[数量]`，无资料弱化且不可点击；
- 当前年度作为资料中心默认定位；
- 点击年/月自动落到范围内最近有资料日期；
- 日内纵轴按真实时分秒排序但压缩空白间隔；
- 默认只显示文件名等轻量信息，点击才加载原始媒体。

## 五、自动扫描

持久扫描源由用户授权配置，绝对路径加密保存。解锁后可自动进行一次增量扫描，也支持手动扫描和暂停/继续。扫描器直接调用后端已有加密入库链路，避免浏览器中转。

源文件删除不等于 LifeGraph 归档删除。系统只标记源缺失，保护长期档案。

## 六、人生图谱联动

首页、全页和年/月视图直接使用结构化资料统计标记“有资料”。资料增长后，人生图谱会自动变得更完整，而不依赖用户每天手工写事件。

## 七、安全边界

- 正文、文件名、原始 metadata、扫描源绝对路径继续加密；
- 为高性能时间范围查询，归一化时间事实作为结构化索引保存；
- 大型媒体继续分块 AES-GCM；
- 自动扫描不会删除 LifeGraph 归档副本；
- `.lifevault` 继续使用 format v3。
