# LifeGraph v0.0.3 稳定发布说明

发布日期：2026-08-06  
版本：v0.0.3  
数据库 schema：v3  
自动化测试：62 passed

## 发布定位

v0.0.3 在 v0.0.2 的年／月／日时间内容闭环基础上，完成内容生命周期管理、全页日图默认入口和个人档案安全设置。该版本可作为后续仓库迁移、备份、搜索与附件能力的稳定基线。

## 正式能力

1. 事件、记忆和计划支持编辑、revision 并发保护和取消编辑；
2. 三类内容支持软删除，并保留原加密正文；
3. 统一回收站支持恢复、彻底删除和清空；
4. 全页连续日期格作为默认解锁入口；
5. 综合首页保留日／月／年三级全范围图谱；
6. 支持修改姓名、出生日期和 PIN；
7. 支持使用恢复凭据重置 PIN；
8. 应用内确认、未保存保护、处理中状态和移动端布局完成收口。

## 数据与兼容性

- 数据库 schema 继续为 v3；
- 从 v0.0.1／v0.0.2 升级时可自动迁移到 v3；
- v0.0.3 不需要新增数据库迁移；
- 修改姓名、出生日期或 PIN 不改变档案 ID；
- 修改 PIN 只重新包装同一主密钥；
- 既有事件、记忆和计划的公历时间与密文保持不变。

## 安全结论

- 业务正文继续采用 AES-GCM 加密；
- PIN 和恢复凭据继续通过 Argon2id 派生包装密钥；
- 软删除不破坏密文；
- 彻底删除才物理移除记录；
- 敏感内容不会以明文写入 SQLite、WAL 或 SHM；
- 运行数据库、密钥文件、日志和缓存不进入发布源码包。
