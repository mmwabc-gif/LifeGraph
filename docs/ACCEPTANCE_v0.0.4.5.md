# LifeGraph v0.0.4.5 验收清单

## 1. 修改恢复凭据

- [ ] 个人设置中显示“修改恢复凭据”区域；
- [ ] 默认可自动生成高强度恢复凭据；
- [ ] 可切换为自定义恢复凭据，并要求至少 12 个字符且两次一致；
- [ ] 修改前必须验证当前 PIN；
- [ ] 当前 PIN 错误时不修改任何密钥槽；
- [ ] 自动生成的恢复凭据只显示一次；
- [ ] 修改后原恢复凭据不能再解锁当前仓库；
- [ ] 新恢复凭据可以解锁当前仓库；
- [ ] 原 PIN 仍可正常解锁；
- [ ] SQLite 中档案与内容密文保持不变。

## 2. 密钥槽状态

- [ ] 个人设置显示 PIN 密钥槽与恢复密钥槽；
- [ ] 显示 Argon2id 算法名称；
- [ ] 显示两个密钥槽最近更新时间；
- [ ] 刷新按钮可重新读取当前状态；
- [ ] 页面和 API 均不返回盐、nonce、包装密文或凭据。

## 3. 安全审计摘要

- [ ] 新仓库包含初始化记录；
- [ ] 修改 PIN 后追加 `pin_changed`；
- [ ] 使用恢复凭据重置 PIN 后追加 `pin_reset_with_recovery`；
- [ ] 更换恢复凭据后追加 `recovery_credential_changed`；
- [ ] 从 `.lifevault` 恢复后追加 `repository_restored`；
- [ ] 摘要只包含操作类型、结果和 UTC 时间；
- [ ] 最多保留 50 条；
- [ ] 不包含 PIN、恢复凭据、姓名、出生日期、标题或正文；
- [ ] 旧版 `vault.json` 缺少新字段时仍能读取安全摘要。

## 4. 备份兼容性

- [ ] 修改恢复凭据前导出的旧备份仍可使用旧恢复凭据验证；
- [ ] 修改恢复凭据后导出的新备份使用新恢复凭据；
- [ ] 旧备份与新备份均不包含凭据明文；
- [ ] 数据库 schema 保持 v3，无需迁移。
