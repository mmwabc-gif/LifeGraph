# LifeGraph v0.0.5.1 验收说明

## 目标

提供“记一记”快捷入口，在首页日／月／年视图和全页日图中直接记录当天个人记忆。

## 验收项

- 首页图谱工具区显示【记一记】按钮；
- 全页日图顶部显示【记一记】按钮；
- 点击按钮后打开页面中央二级窗口，而不是右侧日期抽屉；
- 窗口显示当前日期，并默认保存到当前日期的 day 级记忆；
- 正文必填，标题可选；
- 标题为空时从正文自动生成标题；
- 保存成功后刷新日、月、年内容状态与全页日期格标记；
- 未保存内容关闭窗口时出现确认提示；
- 数据库 schema 保持 v3，无需迁移。
