# LifeGraph v0.0.6 Stable Release

发布日期：2026-08-08

## 定位

v0.0.6 是 LifeGraph 的“搜索、筛选与标签”稳定版。在 v0.0.5 的记录、阅读与富文本记忆基础上，建立第一套面向个人记忆的查找与整理闭环。

## 主要能力

- 记忆可绑定多个标签，并在新增、编辑与阅读时维护；
- 支持直接创建新标签；
- 关键词搜索覆盖解锁后的记忆标题与正文；
- 支持开始日期、结束日期和多标签组合筛选；
- 搜索结果可跳转到对应年/月/日详情并定位目标记忆；
- 日/月/年三级人生图谱支持标签命中高亮；
- 标签管理支持使用次数、新建、重命名和删除；
- 删除标签只解除关联，不删除记忆。

## 数据与迁移

- 数据库 schema：v4；
- 从 schema v3 非破坏性升级；
- 新增 `tags` 与 `memory_tags`；
- 记忆标题与正文继续保持 AEAD 字段加密；
- 标签本身属于整理索引元数据，不包含记忆正文；
- `.lifevault` 格式保持兼容，稳定版生产者版本统一为 `0.0.6`。

## 搜索与筛选语义

- 关键词：标题或正文任一包含即可命中；
- 富文本正文按可见文字检索，不使用 HTML 标签作为搜索内容；
- 时间条件可单独使用开始或结束日期，也可组合成闭区间；
- 多标签条件采用交集语义，即记忆需要同时包含所选标签；
- 地图筛选保留完整人生结构，只对命中和未命中格做视觉区分。

## 当前边界

- v0.0.6 的标签与搜索以“记忆”为第一类内容；
- 事件和计划仍保留原内容管理能力，但尚未进入统一标签与全文搜索；
- 照片、附件、文件扫描、多端同步和 AI 整理不在本版本范围。
