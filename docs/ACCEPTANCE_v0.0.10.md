## 发布结论

v0.0.10 已完成“自动资料时间索引与十字时间轴”阶段，达到稳定归档、Git commit 与 `v0.0.10` tag 条件。

## 核心验收

- [x] schema v8 可非破坏性升级到 schema v11；
- [x] 旧资料时间索引回填不阻塞启动，并支持暂停/继续；
- [x] 年/月/日/小时统计无需全库 metadata 解密；
- [x] 资料中心年/月/日三层横轴可同时显示并直接切换；
- [x] 日内纵轴按时分秒显示轻量资料信息；
- [x] 密集资料支持自适应时间段聚合和分页继续加载；
- [x] 支持上一/下一有资料日期；
- [x] 自动扫描源可增量导入本机普通资料和大型媒体；
- [x] 未变化文件跳过，源文件缺失不删除 LifeGraph 副本；
- [x] 扫描源路径加密保存，并随 `.lifevault` 备份恢复；
- [x] 人生图谱日期可根据结构化时间索引自动点亮资料状态；
- [x] 时间待确认与手工修正闭环有效；
- [x] 年/月/日右侧抽屉不再全库解密附件，当前范围按索引分页读取；
- [x] v0.0.9 大文件、Range 播放、音频兼容、备份恢复能力无回归；
- [x] 应用启动默认进入首页。

## 安全边界

- 私人正文、文件名、原始 metadata 与扫描源绝对路径继续加密；
- 仅规范化时间事实作为结构化查询索引；
- 大型媒体仍使用 chunked-v1 分块 AES-GCM；
- 自动扫描只归档，不执行源目录到 LifeGraph 的危险同步删除；
- `.lifevault` format v3 保持兼容。
