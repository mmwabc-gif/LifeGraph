# 人生图谱 v0.0.5 收口归档

## 版本定位

LifeGraph v0.0.5 是“内容记录与阅读体验”阶段稳定版。该版本在 v0.0.4 的加密、安全、备份与恢复闭环基础上，强化了日常记录、日期详情阅读、富文本记忆和长内容浏览。

## 核心新增

1. 首页和全页视图新增「记一记」快捷入口；
2. 记一记、添加记忆、编辑记忆统一使用 TinyMCE 富文本；
3. 右侧日期详情抽屉支持全屏阅读模式；
4. 抽屉底部新增悬浮上一个 / 下一个有内容日期导航；
5. 抽屉打开时支持键盘左右箭头浏览；
6. 首页和全页视图支持 Alt + Enter 打开详情；
7. 长记忆支持自动折叠与展开。

## 收口判断

本阶段已经形成比较完整的“记录 → 查看 → 阅读 → 编辑 → 浏览相邻内容”的闭环。Markdown 混合编辑在试验后暂缓，保留 TinyMCE 富文本作为唯一日常记忆编辑方式。
