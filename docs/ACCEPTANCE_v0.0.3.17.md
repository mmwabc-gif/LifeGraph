# LifeGraph v0.0.3.17 验收清单

## 个人档案

- [ ] 综合首页和全页日图都能打开“个人设置”。
- [ ] 姓名修改后，首页标题立即更新。
- [ ] 出生日期修改后，人生进度、目标日期和今天位置重新计算。
- [ ] 保存个人档案必须输入正确的当前 PIN。
- [ ] 错误 PIN 不会修改档案。
- [ ] 过期 `revision` 返回冲突，不覆盖较新的档案。
- [ ] 出生日期调整前显示影响提示；超出新范围的内容不会删除。
- [ ] 将出生日期改回后，原公历日期内容重新可见。

## PIN 修改

- [ ] 当前 PIN、新 PIN、确认新 PIN 均有格式校验。
- [ ] 新 PIN 与当前 PIN 相同时拒绝修改。
- [ ] 修改成功后当前会话立即失效并返回锁定页。
- [ ] 旧 PIN 无法解锁，新 PIN 可以解锁。
- [ ] 修改 PIN 不会改变 SQLite 中档案和内容密文。
- [ ] 恢复凭据密钥槽保持可用。

## 恢复凭据重置 PIN

- [ ] 锁定页可打开“使用恢复凭据重置 PIN”。
- [ ] 错误恢复凭据被拒绝。
- [ ] 正确恢复凭据可以设置新 PIN。
- [ ] 重置后旧 PIN 失效，新 PIN 可解锁。
- [ ] 原有事件、记忆、计划均可正常读取。

## 安全与回归

- [ ] 姓名、出生日期、PIN 不以明文进入 SQLite、WAL、SHM 或 `vault.json`。
- [ ] 数据库 schema 仍为 v3，无需迁移。
- [ ] `python -m pytest` 全部通过。
- [ ] `node --check frontend/app.js` 通过。

## 首页视觉调整

- [ ] “你已经走过 X 天。”字号明显大于 v0.0.3.15，且不抢过主标题。
- [ ] 桌面与窄屏下均无换行遮挡或布局跳动。

## 个人设置弹窗

- [ ] 常规桌面窗口中个人设置完整显示且无内部滚动条。
- [ ] 首页与全页视图打开个人设置时表现一致。
- [ ] 小屏或高度不足时可滚动查看全部内容，但不显示滚动条轨道。
