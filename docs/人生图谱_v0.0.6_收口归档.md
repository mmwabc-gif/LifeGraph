# 人生图谱 v0.0.6 收口归档

## 版本定位

LifeGraph v0.0.6 是“搜索、筛选与标签”阶段稳定版。在 v0.0.5 已完成的快捷记录、富文本记忆和抽屉阅读能力上，加入第一套内容整理与回查机制。

## 核心新增

1. 记忆支持多标签绑定、解绑与阅读展示；
2. 记忆搜索支持关键词、日期范围和多标签组合条件；
3. 搜索结果可定位到原始年/月/日详情；
4. 日/月/年人生图谱支持标签命中高亮；
5. 个人设置新增标签管理，支持使用次数、新建、重命名和删除；
6. 标签地图使用结构化关联查询，不逐条解密正文。

## 数据结构

数据库由 schema v3 升级为 v4：

```text
tags
  id
  profile_id
  name
  color
  created_at
  updated_at

memory_tags
  memory_id
  tag_id
  created_at
```

已有业务密文不会因为迁移而被重写。

## 收口判断

当前已经形成：

```text
记录记忆
  ↓
绑定标签
  ↓
关键词 / 时间 / 标签查找
  ↓
定位原日期
  ↓
按标签重新观察整个人生图谱
```

因此 v0.0.6 可以作为稳定节点提交 GitHub 并打 `v0.0.6` tag。

## 当前边界

标签与搜索目前围绕记忆实现。事件和计划仍可正常新增、编辑、删除与回收，但统一标签化和全文搜索建议放到下一阶段，避免在本版本继续扩大范围。
