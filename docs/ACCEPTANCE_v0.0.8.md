# LifeGraph v0.0.8 验收清单

日期：2026-08-09  
数据库 schema：v7  
`.lifevault`：format v2

## 阶段目标

v0.0.8 完成“人生资料系统”：资料不再只是正文的附属文件，而成为可独立存在、具备自身真实时间、可进入人生时间轴并长期加密保存的一级对象。

## 功能验收

- [x] 事件、记忆、计划支持加密附件上传、下载、删除；
- [x] 新建内容时可先选择附件，内容保存后自动绑定；
- [x] 照片支持缩略图和沉浸式预览；
- [x] 图片 EXIF、Office/PDF 内部时间和文件修改时间可用于资料自身时间轴；
- [x] 资料自身时间与父内容日期完全解耦，不会移动父内容；
- [x] 时间识别失败时可自动回退到来源日期或添加/导入时间；异常历史资料可手工归入兜底日期；
- [x] 独立资料无需父事件/记忆/计划即可导入；
- [x] 资料中心提供时间轴/列表两种模式，支持筛选、排序、来源跳转和日期跳转；
- [x] 资料时间轴支持年、月、日多级折叠；
- [x] 右侧详情的事件、记忆、计划和资料支持折叠；
- [x] 资料中心支持主动选择目录、扫描预览、重复检查和批量加密导入；
- [x] 目录导入仅保存相对路径，不保存本机绝对路径；
- [x] 首页顶部加入可切换年月的快捷月历；
- [x] 首页、抽屉月视图和星期视图显示农历、二十四节气与重要传统节日；
- [x] 附件存储按 UUID 前两位分片，旧平铺附件自动兼容迁移；
- [x] `.lifevault` 导出、自动备份、导入检查和恢复采用磁盘流式路径；
- [x] 资料中心按 48 份/批分页追加；
- [x] 图片缩略图仅在进入可视区域附近时解密加载。

## 数据与安全验收

- [x] 数据库 schema 为 v7；
- [x] 附件密文保存为 `.lgatt`，原文件不明文落入 LifeGraph 数据目录；
- [x] 附件文件名、类型、大小、摘要、时间与来源等元数据保持加密；
- [x] 独立资料通过可选 `kind/content_id` 实现，不制造伪内容；
- [x] `.lifevault` format v2 包含附件，并继续兼容 format v1 导入；
- [x] 本地附件分片不会改变 `.lifevault` 内部逻辑路径；
- [x] 备份/恢复过程验证数据库、附件密文、解密结果、大小与 SHA；
- [x] 恢复失败仍可回滚，恢复成功后会撤销现有会话。

## 长期性能验收

- [x] 新附件不会长期堆积在单一目录；
- [x] 旧平铺附件启动后可自动迁移，迁移失败时读取仍兼容；
- [x] 大型 `.lifevault` 不再需要把整个备份包放入内存；
- [x] 资料中心不会一次把所有解密后的资料对象保存在内存；
- [x] 图片列表不会一次性解密所有缩略图。

## 当前边界

- 普通附件单文件上限仍为 50 MB；
- 当前不支持 GB / 数十 GB 单文件的分块加密和断点续传；
- 当前不提供视频封面、时长提取、HTTP Range 随机解密和在线播放；
- 大型媒体与 `.lifevault` 核心备份的长期分层策略留到 v0.0.9；
- 加密元数据无法直接使用普通 SQLite 明文索引，因此复杂资料筛选仍需要分批解密候选记录。
