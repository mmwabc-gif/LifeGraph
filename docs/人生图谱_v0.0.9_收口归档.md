# 人生图谱 v0.0.9 收口归档

日期：2026-08-09  
正式版本：v0.0.9  
数据库 schema：v8  
`.lifevault`：format v3  
大型媒体：chunked-v1

## 阶段定位

v0.0.9 完成“大文件与影音资料”闭环。LifeGraph 的人生资料库从 v0.0.8 的照片、文档与中小附件，扩展到 GB / 数十 GB 视频和其他大型文件，并建立了与此相匹配的断点上传、随机解密播放和分层备份模型。

## 本阶段完成

### 1. 大文件基础设施

- 大型媒体单独存入 `data/media`；
- 每个分块独立 AES-GCM 认证；
- 自适应 4/8/16/32 MB 分块；
- 单文件安全上限 2 TB、最多 65,536 块；
- finalize 逐块认证并计算整文件 SHA-256；
- 支持跨块随机字节读取。

### 2. schema v8 与大文件 API

- `attachments` 正式支持 `blob-v1 / chunked-v1`；
- 新增 `media_id`；
- 上传会话 API 覆盖 create/status/chunk/cancel/finalize；
- 删除大型资料同步清理其原始媒体目录；
- 资料中心正式增加视频类别。

### 3. 浏览器分块上传与性能优化

- `File.slice()` 分块，不整文件进内存；
- 暂停、继续、取消、失败重试、刷新后续传；
- 大文件快速指纹重复检测；
- 单文件 3 路有限并发；
- 1–16 GB 常见视频使用 8 MB 分块；
- 显示实时 MB/s 和预计剩余时间；
- Windows 6.56 GB 文件实测约 82 MB/s。

### 4. 视频元数据与封面

- 视频时长、分辨率、编码识别；
- 浏览器支持格式截取真实画面；
- Matroska / MKV 头部解析；
- 信息型回退封面；
- 封面独立加密存入 `data/previews`。

### 5. HTTP Range 与在线播放

- 标准 Range / 206；
- seek 只解密命中块；
- 大文件流式下载；
- 播放 ticket 不在 URL 暴露登录 Bearer Token；
- 64 MB LRU 解密块缓存仅驻内存。

### 6. 浏览器音频兼容层

- 识别 DTS、AC-3、E-AC-3、TrueHD 等音轨；
- 自动发现 `C:\ffmpeg` 或 PATH 中 FFmpeg；
- 优先生成 224 kbps MP3，必要时回退 AAC；
- 原视频和原音轨保持不变；
- 兼容轨分块加密保存并与视频同步播放；
- 6.56 GB 实机派生 MP3 约 71 MB/s。

### 7. `.lifevault v3` 与媒体分层

- 核心包包含数据库、普通附件、封面和加密媒体 inventory；
- 原始 `data/media` 不进入 `.lifevault`；
- 恢复核心后允许媒体离线，原媒体放回后自动挂接；
- v1/v2 历史备份继续兼容；
- 缺失可重建封面不再阻断核心备份。

### 8. 大型媒体独立增量备份

- 支持指定本地/外置盘备份目录；
- 首次复制全部所需密文块；
- 后续只复制新增或变化文件；
- `.part` + 原子替换；
- 支持备份盘密文 SHA-256 完整校验；
- 不自动删除历史块，避免误删。

### 9. 发布前可靠性与性能收口

- 上传和媒体备份磁盘空间预检；
- 服务端最多 6 个大型分块并发写入；
- 30 天过期未完成会话显式清理；
- 原始媒体逐块 AES-GCM + 整文件 SHA-256 深度校验；
- 登录/资料中心热路径不再扫描历史 `.lifevault`；
- 视频播放、拖动、声音与大型媒体备份完成实机验证。
