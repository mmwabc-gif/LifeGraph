## 数据与安全

- schema 保持 v3；
- AES-GCM 加密正文保持不变；
- 软删除不改写原密文；
- 修改 PIN 只重新包装主密钥；
- 敏感数据不以明文进入 SQLite、WAL 或 SHM；
- 发布包不包含数据库、密钥、日志、缓存或个人数据。
