# LifeGraph v0.0.4 稳定发布说明

发布日期：2026-08-07  
版本：v0.0.4  
数据库 schema：v3  
自动化测试：91 passed

## 发布定位

v0.0.4 在 v0.0.3 的内容生命周期与个人安全设置基础上，完成“可备份、可验证、可迁移、可恢复”的本地加密仓库闭环。该版本可作为后续内容搜索、整理、附件与跨设备能力的稳定基线。

## 正式能力

1. SQLite 一致性快照与 `.lifevault` 加密备份导出；
2. 导入前恢复演练、凭据验证、版本校验和全部密文验证；
3. 正式恢复前安全备份、替换后复验和失败自动回滚；
4. 每天／每周本地自动备份、保留数量和历史管理；
5. 备份健康、超期、失败、损坏和待验证状态；
6. 最近备份一键完整恢复验证；
7. PIN 修改、恢复密钥重置 PIN 和恢复密钥轮换；
8. 密钥槽状态与不含敏感内容的本地安全审计；
9. 个人设置三组结构、恢复密钥归位和个人档案默认只读。

## 数据与兼容性

- 数据库 schema 继续为 v3；
- 从 v0.0.3 覆盖升级不需要数据库迁移；
- `.lifevault` 格式版本保持独立管理；
- 旧备份继续使用导出时的 PIN 或恢复密钥；
- 修改 PIN 或恢复密钥不改变仓库主密钥和业务密文；
- 自动备份策略随仓库元数据迁移，并兼容旧版 `vault.json`。

## 安全结论

- 业务正文继续采用 AES-GCM 加密；
- PIN 和恢复密钥继续通过 Argon2id 派生包装密钥；
- 导出、自动备份和恢复都验证 SQLite、外键、校验摘要与全部密文；
- 正式恢复失败不会丢失原仓库；
- 健康状态和安全审计不包含姓名、出生日期、标题、正文或凭据；
- 发布源码包不包含数据库、密钥文件、备份、日志、缓存或个人数据。

## 当前边界

本版本的自动备份仍保存在同一设备，不能替代异盘或异地备份；暂不包含照片与附件、文件扫描、农历、浏览器插件、多设备同步和云端协作。
