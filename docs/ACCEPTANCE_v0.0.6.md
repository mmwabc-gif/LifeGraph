# LifeGraph v0.0.6 验收清单

## 验收结论

LifeGraph v0.0.6 已完成记忆搜索、时间范围筛选、标签系统、地图标签高亮和标签管理闭环。数据库 schema 升级到 v4。

## 标签验收

- [x] 记一记可选择多个标签；
- [x] 日期详情新增/编辑记忆可选择、取消和新建标签；
- [x] 已有记忆编辑时恢复原标签；
- [x] 记忆阅读卡片展示标签；
- [x] 标签列表批量加载，避免逐条查询；
- [x] 标签管理显示每个标签的记忆使用次数；
- [x] 标签可新建和重命名；
- [x] 重复标签名被拦截；
- [x] 删除标签只解除关联，不删除记忆；
- [x] 删除正在使用的标签后，搜索/地图筛选状态同步修正。

## 搜索验收

- [x] 支持标题与正文关键词搜索；
- [x] TinyMCE 富文本按可见文字搜索；
- [x] 支持开始日期和结束日期；
- [x] 支持多标签交集筛选；
- [x] 无关键词时可只按日期或标签搜索；
- [x] 搜索结果显示标题、时间范围、摘要和标签；
- [x] 点击结果可打开对应详情并定位目标记忆；
- [x] `Ctrl + K` 可打开搜索。

## 地图筛选验收

- [x] 首页和全页视图均提供标签筛选入口；
- [x] 日/月/年三级图谱同步应用筛选；
- [x] 命中格突出、未命中格弱化；
- [x] 完整人生时间结构不因筛选而消失；
- [x] 显示命中记忆及覆盖天/月/年数量；
- [x] 支持一键清除筛选；
- [x] 修改记忆标签后筛选结果自动刷新。

## 兼容与安全验收

- [x] schema v3 可非破坏性迁移到 v4；
- [x] 旧记忆无需重新写入；
- [x] 标题和正文继续加密；
- [x] 搜索只在仓库解锁后执行；
- [x] 搜索条件不写入数据库；
- [x] `.lifevault` 备份格式保持兼容；
- [x] 前端、后端、状态接口和备份生产者版本统一为 0.0.6。
