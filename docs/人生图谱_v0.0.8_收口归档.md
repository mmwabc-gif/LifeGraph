# 人生图谱 v0.0.8 收口归档

日期：2026-08-09  
正式版本：v0.0.8  
数据库 schema：v7  
`.lifevault`：format v2

## 阶段定位

v0.0.8 完成“人生资料系统”。LifeGraph 从以事件、记忆、计划为中心的内容系统，扩展为“人生内容库 + 人生资料库”：照片、文档与其他文件既可以依附内容，也可以独立存在，并按自己的真实时间进入人生图谱。

## 本阶段完成

### 1. 加密资料底座

- 附件正文使用仓库主密钥加密保存；
- 文件名、MIME、大小、SHA 与时间信息继续作为加密元数据；
- 图片支持缩略图与沉浸式原图浏览；
- 内容回收站生命周期与附件生命周期联动；
- `.lifevault` format v2 正式携带附件。

### 2. 资料双重时间关系

- 资料保留“来自哪条内容”的关系；
- 同时拥有独立的 `timeline_date`，不会移动父内容；
- 图片 EXIF、Office/PDF 内部时间、文件修改时间依次参与识别；
- 无法识别时回退到来源日或添加/导入时间；
- 异常历史资料提供手工兜底归属操作。

### 3. 独立资料与资料中心

- schema v7 允许资料没有父事件/记忆/计划；
- 资料中心支持时间轴/列表；
- 图片、文档、其他文件统一浏览；
- 年/月/日多级折叠；
- 时间轴日期与来源内容均可双向跳转；
- 列表中的长文字使用省略显示并支持悬停完整提示。

### 4. 目录扫描与批量导入

- 主动选择本地目录后递归扫描；
- 扫描预览、SHA 重复识别、仓库重复检查；
- 保存相对路径，不保存绝对路径；
- 单次扫描上限 1000 个文件；普通单文件仍限制 50 MB。

### 5. 详情抽屉与首页月历

- 年/月/日新增按钮显示对应粒度；
- 事件、记忆、计划列表分别可折叠；
- 资料超过 6 条时默认折叠；
- 首页标题区新增快捷月历，支持切换年月；
- 公历数字、农历、节气和传统节日叠层显示；
- 节气与传统节日以暖红色突出；
- 抽屉月视图与周视图同步显示农历信息。

### 6. 大型资料库性能加固

- 附件按 UUID 前两位分散到最多 256 个物理目录；
- 旧平铺附件启动时自动迁移并保留回退兼容；
- `.lifevault` 的导出、自动备份、导入检查与恢复均改为磁盘流式路径；
- 资料中心按 48 份/批分页追加；
- 图片缩略图进入可视区域附近才解密加载；
- schema v7 与 `.lifevault` v2 均无需再升级。
